 # Real Estate Website

A modern and responsive real estate website UI developed using HTML, CSS, JavaScript, and Bootstrap, based on a Figma design reference.

## About the Project

This project is a real estate property listing website designed to provide users with a clean and user-friendly interface for exploring properties and discovering real estate opportunities.

The website includes different sections such as a hero/search section, featured properties, properties by city, how it works, customer testimonials, popular real estate markets, best properties, expert team members, and a detailed footer section.

The main goal of this project was to convert a Figma-based UI design into a responsive and functional frontend website using Bootstrap and custom CSS.

## Features

- Responsive navigation bar
- Real estate property search section
- Property listing cards
- Property badges and pricing information
- Properties by city section
- How It Works section
- Customer testimonials
- Best Properties section
- Expert team members section
- Popular real estate markets section
- Responsive footer
- Mobile-friendly responsive layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Figma

## Design

The website UI was created by following a Figma design reference and implementing the design into a responsive frontend layout using Bootstrap components and custom styling.

## Purpose

This project was created as a frontend development practice project to improve skills in:

- Bootstrap
- Responsive web design
- HTML and CSS
- JavaScript
- Figma to HTML conversion
- Website layout and UI implementation
